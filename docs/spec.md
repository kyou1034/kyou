# 薄型分割キーボード 仕様メモ

設計検討の現時点の整理。「決定」「候補・方針」「未決定・要確認」に分けて記録する。

## 1. 決定事項

| 項目 | 内容 |
|---|---|
| 形態 | 薄型の分割キーボード |
| スイッチ | Choc v2 系 |
| 予算 | 1.5万円程度（スイッチを含む。ケース・キーキャップは除く） |
| マイコン | 基板に後付けする |
| メイン基板 | 左右共通のリバーシブル基板 |
| サブ基板 | 右側にトラックボール、左側にスペース・クリック用キーを別基板で取り付ける |
| 左右接続 | 有線（TRRS）。無線には対応しない |

### 実現したい機能の優先順位

1. 薄型・分割
2. 自作PCB（ソケットは自分ではんだ付け）
3. トラックボール
4. アンダーグローLED（実装済みで）
5. キーごとのLED（実装済みで）
6. ソケットの実装

## 2. 候補・方針

| 項目 | 候補・方針 |
|---|---|
| マイコン | RP2040-Zero（互換品を含む）×2 |
| 基板発注先 | JLCPCB |
| アンダーグローLED | 実装は依頼せず、テープLEDを自分で仕込む |
| サブ基板 | トラックボール用とキー用を兼ねた共通の1種類にし、設計データを2種類（メイン・サブ）に抑える |
| センサー | PMW3610（素子＋レンズで900円）。QMK標準ドライバにないため、ドライバの自作または実装依頼が必要 |

## 3. 未決定・要確認

- [ ] センサーの最終選定（PMW3610 / PMW3360 / ADNS-5050）
- [ ] メイン基板が100mm以内に収まるか
- [ ] 調達：テープLED用レベルシフター
- [ ] 調達：TRRSジャック・ケーブル
- [ ] 調達：34mmボール
- [ ] サブ基板とメイン基板を接続するピンの割り当て
- [ ] 左右で別のピン設定にするファームウェアの検証

| PMW3360 を使う場合 | 約1.4万円 |
